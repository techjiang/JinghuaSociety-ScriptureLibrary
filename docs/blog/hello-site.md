# 开张帖：为什么我又双叒建站了

2026 年了，短视频和 AI 问答满地都是，还有人吭哧吭哧写静态博客，
听起来挺行为艺术的。但说实话，有些东西替代不了，这篇就说说为什么。

## 写博客到底图什么

### 图一个「不被打断」的脑子

刷短视频是别人喂给你，写博客是你自己嚼。一篇文章从选题到查证到成文，
信息在自己脑子里过了好几遍，最后留在脑子里的才是自己的。
我写 [HTTP 缓存详解](../tech/http-cache.md) 之前，以为自己门儿清，
写完才发现「ETag 和 Last-Modified 谁优先」这种细节一直是糊的。
**写作是学习效果的质检员**，糊弄不过去的那种。

### 图一个自己找得回的仓库

微信收藏、浏览器书签、Notion、备忘录……工具换了一茬又一茬，
当年存的东西跟着工具一起迁移、一起吃灰。自己的站就不一样：
十年后它还在，搜个关键词，当年那个坑怎么爬出来的，白纸黑字。

### 图一个「我在」的证据

社交媒体上的账号是租来的，平台说没就没，说限流就限流。
自己的域名、自己的服务器（或者一个 GitHub 仓库），所有权清清楚楚。
互联网精神那套话就不多说了，落到实处就一条：**我的地盘我做主**。

## 这个站写什么

四区：

- **教程**：动手向，照做能跑起来；
- **技术**：原理向，把一件事讲透；
- **资源**：工具和路线，亲测才收录；
- **手札**：就是现在这个区，随笔和记录。

不追热点。热点文章保质期按天算，我想写保质期按年算的东西。
某个框架出了新版本？等技术尘埃落定、社区吵明白了再写不迟。

## 关于「精华社 · 藏经阁」这个名字

有人问：都 2026 年了，怎么起了个像古代书楼的名字。
原因很简单：**这个站干的就是「藏经」的事** —— 把散落各处的技术知识，
挑好的、验证过的，分门别类收进来，谁都能来查、来取。

经不是宗教的经，是「经过实践检验」的经。阁也不是谁的阁，
是所有来查资料的人的阁。名字是老派了点，但比「XX 的前端学习笔记」
这种烂大街的标题好记，也好玩。

## 写给谁

主要是写给我自己 —— 当学习笔记。但如果恰好你也在这条路上，
那这些文章对你有用，就是赚到。观点不同太正常了，
拿出来吵吵，越辩越明。

## 更新频率

不立 flag。说「周更」的站，一半死在了第三周。
我的节奏：教程每月一两篇，技术随缘，手札想起来就写。
宁可慢，不要停。

## 最后

如果你也在考虑建个自己的站，别纠结工具了。
VuePress、Hexo、Astro、甚至手写 HTML，都行。
真正难的从来不是「用什么搭」，是「写什么、能不能坚持下去」。
