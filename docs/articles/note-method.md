# 我的笔记方法：从收集到调用

我的笔记史是一部「折腾史」：Evernote 精细分类 →
Notion 数据库 → Obsidian 双链 → 现在**懒人三层流**。
越用越简单。这篇说现状，也说为什么「完美系统」
总是失败。

## 一、三层流水线

```text
① 速记层（ inbox ）：一切先进来，不分类
② 整理层（ notes ）：有值的挪进来，加工
③ 输出层（ posts ）：写明白的，发出去
```

### ① 速记层：零摩擦

- **工具**：手机备忘录 + 微信「文件传输助手」+
  浏览器书签「待读」；
- **原则**：**别分类**。链接、报错、灵感、待办 ——
  一股脑丢进去；
- **节奏**：每天清一次（5 分钟），该进② 的进②，
  没用的删。

**这层的唯一 KPI 是「不丢」** —— 想到什么三秒内
记下，别让「打开 App → 选文件夹 → 写标题」
这套仪式杀死记录欲。

### ② 整理层：每周一次

- **工具**：Obsidian（本地 Markdown）；
- **原则**：**只整理「可能再用」的**。
  命令速查、踩坑记录、读过的文摘要 ——
  用自己的话重写一遍（不是摘抄）；
- **结构**：文件夹三层封顶，
  双链「爱用不用」—— 搜索能找到就不分类。

「用自己的话重写」这步是关键：**抄下来的笔记是别人的，
重写过的才是自己的。** 重写时卡壳的地方，
就是没真懂的地方（标记，回头补）。

### ③ 输出层：每月几篇

- **工具**：本站（VS Code + Markdown + git）；
- **原则**：**输出是笔记的质检**。一个知识点
  能写成「别人看得懂的文章」，才算真会了；
- **关系**：文章是②的「精装修版」——
  ② 是毛坯，③ 是样板间。

本站技术区的文章，九成来自 ② 层笔记的
「讲透升级」。

## 二、为什么「完美系统」都失败了

我折腾过的系统（和死因）：

```text
Evernote 十级分类     → 死因：整理时间 > 记录时间
Notion 数据库视图     → 死因：为了填字段而填字段
双链图谱              → 死因：忙着连链接，忘了学知识
每日模板              → 死因：三天没写，模板成了负罪感
```

**共性：系统比内容重要了。**
笔记的目的是「用」，不是「好看」。

现在的系统丑得要死（一个文件夹 + 搜索），
但**活过了两年，还在每天用** —— 可持续性
打败了所有优雅。

## 三、几个具体技巧

### 命令/速查类：一篇「作弊纸」

所有常用命令（git/docker/linux）写一篇
「作弊纸」，用的时候 `Ctrl+F`。比翻历史强一百倍。
（本站的 [Linux 命令](../../library/tech/linux-commands/)
就是这么来的。）

### 报错类：原文 + 解法 + 原因

```markdown
## [报错信息第一行]

环境：Node 22、VuePress 2
解法：xxx
原因：yyy（理解了才写，不理解写「待补」）
```

**三个月后搜报错，先搜自己的笔记** ——
踩过的坑，别再踩第二次。

### 读书/文章类：三段式

```markdown
## 《书名》/ 文章标题

**讲了什么**：三句话
**我的想法**：哪对、哪存疑、怎么用
**行动**：要改的一个习惯 / 要试的一个方法
```

「我的想法」那段是精华 —— 没有它的读书笔记
是抄书。（本站的[读书笔记们](./reading-js-book/) 是这个格式。）

### 灵感类：不评判，先记

「想做个工具」「这个效果怎么实现的」——
先记，别判断「靠不靠谱」。**判断是整理层的事，
记录层只负责不丢。**

## 四、工具链现状（供参考）

```text
收集：手机备忘录（语音转文字也在这）+ 微信传输助手
待读：浏览器书签「Read Later」+ Pocket
整理：Obsidian（本地，git 备份）
输出：本站（VS Code + git）
```

**没有全平台同步的执念** —— 速记在手机、
整理在电脑，各司其职。真要在手机上看整理后的？
Obsidian 移动端凑合能看，不急。

## 五、给不同人的建议

```text
完全没笔记习惯的    → 先用手机备忘录，坚持一个月再说
觉得整理麻烦的      → 一个文件夹 + 搜索，别分类
爱折腾的            → Obsidian 随你折腾，但每月问自己「用了吗」
要公开输出的        → 直接开博客（本站教程），笔记=文章草稿
```

**最中肯的一条**：别在工具上超过总时间的 10%。
九成时间应该是「记内容、写想法」，不是「配插件、
调模板、画图谱」。

## 小结

我的笔记三层流：**速记不分类（ inbox ）、
整理重写一遍（笔记）、输出讲给人听（文章）**。
系统很简单，甚至有点糙 —— 但它在持续运转，
产出着本站的一百多篇文章。**笔记的终点不是「漂亮」，
是「调用」——用上的笔记，才是好笔记。**
