## 写在明处的几句话

- 文章里的命令、代码，**都是在站长的机器上真跑过的**，跑不通会注明；
- 会注明软件版本，因为版本一换，很多经验就作废；
- 观点仅代表站长自己，说错了欢迎来掰扯，GitHub 上提 issue 就行。
