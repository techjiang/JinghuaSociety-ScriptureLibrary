# 常用网站导航

浏览器书签里的常客，按用途分类。标准同上：常打开、真好用。

## 一、查文档

| 网站 | 干嘛的 |
| --- | --- |
| [MDN](https://developer.mozilla.org) | 前端标准文档，权威出处 |
| [javascript.info](https://zh.javascript.info) | 最系统的中文 JS 教程 |
| [Can I use](https://caniuse.com) | 查某个 CSS/JS 特性各浏览器支持度 |
| [DevDocs](https://devdocs.io) | 聚合文档，一个站查几十种技术，离线可用 |
| [Roadmap.sh](https://roadmap.sh) | 技术路线图，查漏补缺 |

兼容性问题上 `Can I use` 一查一个准，再也不用猜「这个属性 IE 支不支持」。

## 二、写代码

| 网站 | 干嘛的 |
| --- | --- |
| [GitHub](https://github.com) | 代码托管 + 全球最大开源社区 |
| [Stack Overflow](https://stackoverflow.com) | 报错了先来这搜，八成有答案 |
| [regex101](https://regex101.com) | 正则在线测试 + 逐字符解释 |
| [CodePen](https://codepen.io) | 前端小 demo 速写本，看别人炫技 |
| [JSFiddle](https://jsfiddle.net) | 同上，更朴素 |

SO 提问前记得先搜 —— 大部分「奇怪报错」都被问过八遍了。

## 三、学与练

| 网站 | 干嘛的 |
| --- | --- |
| [freeCodeCamp](https://www.freecodecamp.org) | 免费全栈课程 |
| [LeetCode 力扣](https://leetcode.cn) | 刷题 |
| [Frontend Mentor](https://www.frontendmentor.io) | 照设计稿写页面 |
| [Codewars](https://codewars.com) | 游戏化刷题 |
| [exercism](https://exercism.org) | 多语言练习，有导师反馈 |

刷题顺序建议：力扣按「探索」里的初级算法刷起，别一上来冲中等，
容易怀疑人生。

## 四、看资讯

| 网站 | 干嘛的 |
| --- | --- |
| [Hacker News](https://news.ycombinator.com) | 科技圈风向标 |
| [V2EX](https://www.v2ex.com) | 中文创意工作者社区 |
| [掘金](https://juejin.cn) | 中文技术文章 |
| [InfoQ 中文](https://www.infoq.cn) | 偏架构与工程实践 |
| [阮一峰的网络日志](https://www.ruanyifeng.com/blog/) | 科技爱好者周刊，每周五更新 |

资讯类每天扫标题就行，别沉迷。深度阅读靠书籍和文档，
碎片资讯只是保持敏感度。

## 五、工具类

| 网站 | 干嘛的 |
| --- | --- |
| [transform.tools](https://transform.tools) | 格式转换大全 |
| [JSON Crack](https://jsoncrack.com) | JSON 可视化 |
| [Excalidraw](https://excalidraw.com) | 手绘风画图 |
| [Carbon](https://carbon.now.sh) | 代码截图美化 |
| [TinyPNG](https://tinypng.com) | 图片压缩，立竿见影 |
| [Squoosh](https://squoosh.app) | 图片压缩 + 格式转换，Google 出品 |

图片上传前过一遍 TinyPNG，体积能瘦 70%，画质几乎无损，
这是性价比最高的「性能优化」。

## 六、设计参考（前端加分项）

| 网站 | 干嘛的 |
| --- | --- |
| [Dribbble](https://dribbble.com) | 设计灵感，UI 动效 |
| [Awwwards](https://www.awwwards.com) | 网页设计奖项，神仙打架 |
