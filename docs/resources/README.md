# 资源

这一区是本站的「货架」：站长自己真在用的工具、走过的学习路线、
常翻的网站。收录标准就一条：**自己用过，觉得好**。广告、互推、
没打开过第二次的，不上架。

## 特别说明

互联网的资源朝生暮灭，链接失效、课程下架都是常事。
每条收录时都注明了使用场景，万一哪天网址挂了，
按描述也能搜到替代品。发现哪条失效了，欢迎来issue里说一声。
