# 开发者常用工具

装机清单类文章。都是站长电脑里真装着的，按使用频率排序。
原则：免费优先，一个领域只留一个最顺手的。

## 一、编辑器：VS Code

[下载](https://code.visualstudio.com)，免费，插件生态无敌。
配置和插件清单在 [前端开发环境搭建](../tutorial/frontend-env.md) 里写过，
不重复。

备选：[JetBrains 全家桶](https://www.jetbrains.com)（学生免费用，重装箱即用）、
[Zed](https://zed.dev)（Rust 写的，快，但生态还年轻）。

## 二、终端

- **Windows Terminal**（微软商店）：Windows 上唯一指定终端；
- **Warp](https://www.warp.dev)**：AI 加持的现代终端，块状输出很清爽，
  macOS 首发，现在 Windows 也有了；
- **iTerm2**（macOS）：老牌劲旅，配 Oh My Zsh 是经典组合。

## 三、API 调试

- **[Hoppscotch](https://hoppscotch.io)**：开源、浏览器直接用、不用装。
  个人项目调试第一选择；
- **[Apifox](https://apifox.com)**：国产，接口文档 + 调试 + Mock 一体，
  团队协作向；
- **[Postman](https://www.postman.com)**：老牌，功能全但越来越重，
  团队已经在用了就继续用，新项目我推荐前两个。

## 四、数据库客户端

- **[DBeaver](https://dbeaver.io)**：免费版支持几乎所有数据库，
  一个工具连全家；
- **[TablePlus](https://tableplus.com)**：好看好用，免费版有限制；
- **Navicat**：收费，国内公司出镜率高，不评价。

## 五、设计/截图/录屏

- **[Excalidraw](https://excalidraw.com)**：手绘风格画图，架构图、流程图
  神器，免费开源；
- **[Snipaste](https://www.snipaste.com)**：截图 + 贴图，F1 截图 F3 贴到
  屏幕最上方，对着抄代码/对设计稿必备；
- **[ScreenToGif](https://www.screentogif.com)**：录屏转 GIF，
  写教程演示动作用；
- **[OBS Studio](https://obsproject.com)**：真要录长视频还是它，
  免费开源专业级。

## 六、效率杂项

- **[Everything](https://www.voidtools.com)**（Windows）：文件名秒搜，
  装机必备，用了回不去；
- **[uTools](https://u.tools)**：国产效率工具集，插件丰富，快捷键呼出；
- **[PowerToys](https://learn.microsoft.com/windows/powertoys)**（Windows）：
  微软官方玩具箱，窗口布局、批量改名、取色器都好用；
- **[Raycast](https://www.raycast.com)**（macOS）：启动器天花板，
  Alfred 的现代替代。

## 七、在线小工具

- **[JSON Crack](https://jsoncrack.com)**：JSON 可视化，一眼看清嵌套结构；
- **[transform.tools](https://transform.tools)**：各种格式互转，JSON 转
  TS 类型、时间戳转换、编解码，一个站全包；
- **[carbon.now.sh](https://carbon.now.sh)**：代码截图美化，分享代码
  片段颜值拉满；
- **[excalidraw 同款白板**](https://excalidraw.com)：上面说过，太常用
  放两个入口。

## 八、AI 辅助（2026 年版）

Cursor、GitHub Copilot、Claude、ChatGPT 这些就不放链接了，官网都好找。
说两句使用心得：

- **补全用 Copilot/Cursor**，写业务代码提效明显；
- **读代码、排错、写脚本用对话类**，比搜索快，但结论要自己验；
- 生成代码当「草案」看，别当「答案」抄 —— 它看着对和真对是两回事，
  上线前自己读一遍。

## 小结

工具这事，甲之蜜糖乙之砒霜。上面全是我的蜜糖，你用着不顺就换，
别纠结。真正提高效率的从来不是工具本身，是**你记得用它** ——
收藏夹吃灰的工具，装一百个也是零。
