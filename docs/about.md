**精华社 · 藏经阁** 是一个由同好共建的技术文库：把散落各处的计算机与互联网知识，
挑好的、验证过的、讲成人话的，分门别类收进来，谁都能来查、来取、来添。

## 我们在做什么

一句话：**把技术知识，整理成「找得到、看得懂、用得上」的样子**。

具体是四类内容：

- **教程**：动手向。一步一步照做就能跑起来，不跳步，不省略；
- **技术**：原理向。把一件事讲透，但只讲「够用的深度」，不堆术语；
- **资源**：工具、书单、网站。只收自己真用过的，不收广告钱；
- **文章**：随笔、读书笔记、踩坑复盘。真人真事真感受。

## 为谁而建

- **正在路上的学习者**：被海量资料淹死，需要有人先筛一遍；
- **孤独的开发者**：想找个地方翻旧账、查命令、对思路；
- **愿意分享的同好**：写的东西有人看、有人用、有人反馈。

## 阁规三条

1. **亲测才写**：文章里的命令和代码，都是作者亲手跑过的，跑不通会注明坑在哪；
2. **人话优先**：术语要用，但要用完解释。写「说人话」的文档，不当术语复读机；
3. **署名负责**：每篇文章都属名作者。观点可以争论，事实必须可靠。

## 怎么运转

- 内容用 Markdown 写，存在 [GitHub 仓库](https://github.com/techjiang/JinghuaSociety-ScriptureLibrary)，
  提交后自动构建部署（GitHub Actions）；
- 任何改动都有版本记录，改错了能回滚；
- 收录标准、排版规范、友链规则，都写在明处（见[加入](./join.md)）。

## 技术栈

VuePress 2 + Plume 主题，纯静态，部署在 GitHub Pages。
