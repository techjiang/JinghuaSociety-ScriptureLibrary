# 荣誉榜

名人堂记**写文章的人**，荣誉榜记**让文章更靠谱的人**。

错别字、失效链接、过时命令、写反的分支名——正是这些不起眼的较真，
让阁里的每一篇都敢被人照着做。这里为他们署名。

## 提名方式

1. 在文章下留言，或到 [GitHub Issues](https://github.com/techjiang/JinghuaSociety-ScriptureLibrary/issues) 开一个 issue；
2. 写清「哪一篇、哪一段、错在哪、正确的是什么」；
3. 编辑部每月一审，合并后登记到上表。

> 修 bug 和写文章同样值钱。**你较的那一秒真，是读者少踩的一个坑。**

## 怎么把自己加到这一页

1. 编辑 `docs/honor-roll.md`，在「纠错与勘误」表里加一行；
2. 提 Pull Request，标题写 `add: 荣誉榜登记 - 你的昵称`；
3. 合并后自动部署上线。

也可以直接把线索发到 Issues，由编辑部代录。
