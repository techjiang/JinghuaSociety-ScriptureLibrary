友链位正在征集。**藏经阁不只有技术** —— 技术、日常、生活随笔、
工具资源类的站点都欢迎交换。要求就三条：

1. 站点**内容相关**（前端、后端、运维、数据库、编程随笔，
   以及生活日常、个人成长类都行，不限于纯技术）；
2. 域名是自己的，内容原创为主，不是纯采集站；
3. 上线超过一个月，有至少五篇像样的文章。

申请方式：在 [GitHub 仓库](https://github.com/techjiang/JinghuaSociety-ScriptureLibrary) 提个 issue，
附上**站点名 + 链接 + 一句话简介 + 头像地址 + 所属分类**（技术 / 日常 / 资源 / 生活），
掌柜看到了就加。
