# 友情链接

这一页放掌柜常逛的技术站点。不是广告，是**自己真的每周都打开**的地方。

## 交换友链

欢迎交换。要求就三条：

1. 站点是**技术相关**的（前端、后端、运维、数据库、编程随笔都行）；
2. 域名是自己的，内容原创为主，不是纯采集站；
3. 上线超过一个月，有至少五篇像样的文章。

申请方式：在 [GitHub 仓库](https://github.com/techjiang/JinghuaSociety-ScriptureLibrary) 提个 issue，
附上**站点名 + 链接 + 一句话简介 + 头像地址**，掌柜看到了就加。
