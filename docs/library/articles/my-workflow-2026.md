# 我的 2026 开发工作流

每年都会调整工作流，今年这套用了大半年，比较稳定，写出来供参考。
不一定适合你，但每个选择背后的理由，可能对你有启发。

## 一天的时间块

```text
09:00 - 09:30  看消息、回issue、过一遍昨天的TODO
09:30 - 12:00  深度工作块①（最难的活放这，脑子最清醒）
12:00 - 13:30  午饭 + 散步（雷打不动，下午效率靠它）
13:30 - 15:30  协作块：开会、Code Review、结对
15:30 - 18:00  深度工作块②（写代码/写文档）
18:00 - 18:30  收尾：写明日TODO、整理笔记
晚上            ！！不碰工作代码（重要，见下）
```

![一天的时间块安排](/images/workflow-timeline.svg)

*图：上午 block 给深度工作，晚上留给生活*

核心原则：**最难的活放最清醒的时候**。我试过把深度工作放下午，
结果一开会就废半天，晚上加班补，恶性循环。
现在上午谁也别想约我开会，日历上直接 block 掉。

## 晚上为什么不碰代码

去年有段时间晚上回家还写代码，结果：

- 睡眠变差，躺床上还在想那个 bug；
- 白天效率更低，晚上补更多，循环；
- 陪家人的时间也没了。

后来立了规矩：**晚上只做不烧脑的事** —— 看书（非技术）、
看剧、遛弯、打游戏。一开始手痒，坚持两周后发现
白天效率高了不止一点。工作流不是把自己榨干，
是让单位时间的产出更高。

## 工具链

### 笔记：三段式

1. **速记**（碎片想法、报错信息）：手机备忘录 + 微信文件传输助手，
   不求结构，先留住；
2. **整理**（当天/当周有价值的内容）：搬进 Obsidian，
   按主题归档，双向链接串起来；
3. **输出**（真正搞明白的）：写成文章发到
   [本站](/articles/)，接受公众检验。

知识管理的本质不是「存」，是**让信息在需要时找得到**。
所以我只认真整理「可能再用到」的，其他速记完就扔。

### 代码：模板化一切

新项目不从零开始，本地有个 `templates/` 目录：

- `vue-template`：Vite + Vue + TS + ESLint + Prettier + Vitest，
  `pnpm create` 一下全齐；
- `node-api-template`：Express + Prisma + Zod 的基础架子；
- `docs-template`：就是本站这套 VuePress + Plume 的配置。

每次新项目省半小时配置，更重要的是**不会漏配东西**
（比如上次忘配 ESLint，代码风格漂了半个月才发现）。

### 终端：alias 是复利

我的 PowerShell profile 里躺着这些：

```powershell
Set-Alias -Name g -Value git
function dev { npm run docs:dev }      # 本站专用
function glog { git log --oneline --graph -20 }
function ports { Get-NetTCPConnection | Where-Object State -eq 'Listen' | Select-Object LocalPort, OwningProcess }
```

每天敲几十次命令，每次省两秒，一年下来……
反正 `ports` 那个查端口占用，救我狗命不止一次。

### AI：当副驾驶，不当司机

日常用法：

- **写样板代码**：CRUD、测试用例、类型定义，让它打草稿我改；
- **读陌生代码**：贴一段让它解释，比我自己啃快；
- **报错诊断**：贴错误信息先问一嘴，经常直接给对方向。

但有一条纪律：**它写的代码我全读一遍再提交**。
看着对和真对是两回事，上周它就给了我一个看着能跑、
实际边界条件全错的排序函数。方向盘得自己握着。

## 每周节奏

- **周一上午**：定本周三件事（只定三件，多了完不成）；
- **周五下午**：清 TODO、写周报、把值得写的整理成笔记；
- **周末**：不写工作代码。逛 [V2EX](https://www.v2ex.com)、
  看番、打游戏，或者折腾自己的站（对，本站就是周末产物）。

## 身体是最后的瓶颈

25 岁前不信，现在信了：

- 显示器垫高，脖子前倾真的会疼；
- 每小時起来接杯水，顺便走两步；
- 机械键盘 + 腕托，手腕感谢我；
- 咖啡因下午四点后不碰。

这些不是养生玄学，是**可持续性工程**。
倒下了，再好的工作流也是别人的。

## 小结

工作流的本质是**减少决策损耗**：什么时候干什么、
东西放哪、用什么工具，都提前决定好，
把脑力留给真正难的问题。
