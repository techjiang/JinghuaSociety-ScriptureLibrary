# 我的书桌与装备

程序员一天十几个小时在桌前，这套装备就是
「生产工具 + 健康投资」。写写我的配置和心得。
原则：**够用就好，不为发烧**。

## 一、椅子：最值得花钱的一件

很多人舍得买键盘，凑合椅子。搞反了 ——
键盘决定手感，椅子决定**腰和颈椎**。

我的方案：**人体工学椅（二手大牌）+ 腰靠**。
没上 Herman Miller（买不起），
二手 Aeron/Contessa 一两千，比新的入门款强。

**比椅子更重要的习惯**：

- 坐 45 分钟站 15 分钟（升降桌是神器，
  没有就定闹钟起来接水）；
- 屏幕顶端与眼睛平齐 —— 这条治低头，
  用显示器支架或者垫几本书（本站就是这么干的）。

## 二、显示器：一大解千愁

27 寸 2K 起步，能上 4K 更好。写代码的分屏需求
（编辑器 + 浏览器 + 终端）是刚需，两个小屏
不如一个大屏 + 软件分屏。

**护眼设置比参数重要**：

- 亮度跟随环境（晚上调暗，别大黑屋亮瞎眼）；
- 开「夜间模式/护眼模式」（色温调暖，
  刚开始像糊了层黄，一周就回不去了）；
- 20-20-20 法则：每 20 分钟看 20 英尺外 20 秒。

## 三、键盘：看你的手

我的路线：薄膜 → 青轴（被室友追杀）→ 茶轴（安静了）
→ 静电容（贵但值）。

给选择困难症的建议：

- **宿舍/开放办公室**：茶轴/红轴/静音轴，别碰青轴，
  会 social death；
- **预算有限**：百元级 IKBC/高斯，别碰杂牌；
- **手指敏感**：直接静电容（HHKB/Niz），
  一天八小时的东西，手会谢谢你。

**键位比轴体重要**：Home/End/PageUp 有没有、
F 区全不全、配列习不习惯 —— 这些天天用，
轴体一周就习惯了。

## 四、鼠标：人体工学是刚需

普通鼠标用两年，手腕开始酸。换了
垂直鼠标（垂直握持，手腕自然姿势），
酸胀感消失。配合触控板交替用。

重度快捷键用户直接上**轨迹球**
（手指不用动，靠拇指滚球）—— 我没到那境界，
但见过用得很爽的。

## 五、桌面理线与「低反射」

- **理线**：桌底理线架 + 扎带，线不落地。
  桌面干净，心也静一半（真的）；
- **显示器背后贴 LED 灯带**（ bias lighting ）：
  减少屏幕和背景的亮度差，眼睛舒服很多，
  晚上氛围也好了；
- **桌垫**：大号皮革/羊毛垫，手感 + 降噪 +
  桌面统一感，几十块提升最大。

## 六、软件层面的「装备」

硬件之外，天天用的还有：

- **终端**：Windows Terminal + Oh My Zsh（WSL），
  等宽字体 JetBrains Mono；
- **编辑器**：VS Code + 一套精简插件
  （本站有篇[插件清单](../vscode-extensions.md)）；
- **浏览器**：工作/个人两个 profile，
  书签和扩展不打架；
- **笔记**：Obsidian（本地 Markdown，
  不怕倒闭，本站文章草稿都在这）。

## 七、不折腾清单

也踩过坑，说说不买的：

- **RGB 全家桶**：炫三天，之后只开白光
  （还更费电）；
- **第三块显示器**：幻想「效率翻倍」，
  实际「扭头更勤，脖子更酸」。两块封顶；
- **机械键盘客制化**：进坑是无底洞，
  量产够用党及时收手（我收住了，骄傲）；
- **升降桌电动版**：值得，但先确认
  你能不能坚持「站着」这个动作本身。

## 八、预算分配建议

```text
椅子 > 显示器 > 键盘 > 鼠标 > 桌搭配件
```

同样预算，往「椅子 + 显示器」砸 —— 
这两个直接关联健康，其他的都是体验升级。

## 小结

程序员装备的核心不是「发烧」，是
**天天用的东西别将就，一天两小时以上的
交互值得投资**。椅子买好的、屏幕买大的、
键盘买合适的，剩下的等真的需要再买。
