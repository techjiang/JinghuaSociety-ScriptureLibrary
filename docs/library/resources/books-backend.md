前端书单讲「怎么把页面做出来」，这份讲「页面背后的世界怎么运转」。
后端和基础的底子，决定了你是「调包侠」还是「工程师」。
同样原则：只收读过的。

## 一、语言深入

### 《Effective Java》（第 3 版）

Java 的 90 条军规。不是入门书，是「写了两三年 Java
突然发现自己写的都是反模式」时读的书。条条是坑里爬出来的经验。

### 《Effective Python》（第 2 版）

Python 版军规。每一条都短，适合通勤读。90 条读下来，
Python 的「地道写法」就有了。

### 《Go 语言圣经》（The Go Programming Language）

Go 的权威教程。作者之一是 Go 团队成员。薄，
把「接口、并发、channel」讲得明明白白。想懂 Go 并发，读它。

## 二、数据库

### 《MySQL 技术内幕：InnoDB 存储引擎》

国内 MySQL 原理的第一选择。索引、事务、锁的章节
配合本站的[索引篇](../mysql-index.md) 读，效果翻倍。

### 《高性能 MySQL》（第 4 版）

厚如砖头，当手册。慢查询优化、Schema 设计、复制与高可用
都覆盖。工作中遇到 MySQL 问题，翻它比搜博客系统。

### 《Redis 设计与实现》

作者 adiaf。把 Redis 的每种数据结构、事件模型、持久化
源码级讲清。想「真懂 Redis」（不是会用五条命令），读这本。
配合本站的 [Redis 入门](../redis-basics.md)。

## 三、网络与协议

### 《图解 HTTP》

入门友好，图多。协议、首部、状态码一遍过。薄，
一个周末。想深入再看下面两本。

### 《TCP/IP 详解 卷1：协议》

网络协议的圣经。厚重，但当参考书极合格。
配合本站的 [TCP 握手](../tcp-handshake.md) 读，先建立直觉再抠细节。

### 《Web 性能权威权威指南》

前后端通吃（前端书单也推了）。网络层优化部分
（TCP 调优、HTTP/2、QUIC）是精华。

## 四、操作系统与底层

### 《深入理解计算机系统》（CSAPP）

程序员的内功心法。从二进制到内存到并发，一遍下来
「计算机怎么工作」的直觉就有了。难，但值得啃两遍。

### 《操作系统导论》（OSTEP）

免费在线读（[pages.cs.wisc.edu](https://pages.cs.wisc.edu/~remzi/OSTEP/)）。
虚拟化、并发、持久化三大件讲得极好，还有幽默感。
比《现代操作系统》好读。

### 《Linux/UNIX 系统编程手册》

Linux 系统调用的权威手册。写 C/做系统编程的备着，
当字典查。

## 五、分布式与架构

### 《数据密集型应用系统设计》（DDIA）

分布式领域公认最佳。复制、分区、事务、一致性、流处理 ——
每章都是「分布式系统设计的为什么」。有免费在线版
（[ddia.virtnet.xyz](https://ddia.virtnet.xyz) 民间翻译，
有能力支持正版）。

### 《微服务架构设计模式》

Chris Richardson。微服务的「为什么 + 怎么做」，
模式分类清晰（Saga、CQRS、BFF…）。不是无脑吹微服务，
该用单体时它也会说。

### 《Designing Data-Intensive Applications》配套：《数据密集型》

重复了，跳过。真正该提的是《架构整洁之道》——
Bob 大叔。讲「什么是好架构」：依赖方向、边界、分层。
薄，观点鲜明，值得和团队一起读。

## 六、软技能延续

- **《人月神话》**：软件工程的古老经典，
  「加人赶进度」的悖论至今成立；
- **《卓有成效的程序员》**：效率习惯，Tips 密集；
- **《团队协作的五大障碍》**：带团队前读，少走两年弯路。

## 七、阅读路线建议

```text
先打底（可选）：图解 HTTP → CSAPP/OSTEP（按兴趣选）
工作驱动：MySQL 技术内幕 + 高性能 MySQL（遇到问题翻）
深入原理：Redis 设计与实现 → DDIA（分布式世界观）
语言内功：Effective Java/Python/Go（按主语言选一本）
```

**和前端书单的关系**：两份不是二选一。前端到了高级阶段，
瓶颈往往在后端和基础（性能调优看网络、全栈要看数据库、
架构要看分布式）—— 那时候回来翻这份。

## 小结

后端书单核心六本：**OSTEP（系统）+ 图解 HTTP（网络）+
MySQL 技术内幕（库）+ Redis 设计与实现（缓存）+
Effective 系列（语言）+ DDIA（分布式）**。
读完这份，你看前端项目的眼光会不一样 ——
你能看到「请求背后」的整个世界。
