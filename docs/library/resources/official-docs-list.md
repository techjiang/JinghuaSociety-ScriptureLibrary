## 七、怎么查文档（元技能）

1. **站内搜索优先**：MDN/Vue/React 的搜索框比 Google 准 ——
   「mdn flexbox」直达；
2. **URL 里猜版本**：`vuejs.org/v2/guide` 是 Vue2 文档 ——
   看版本号，别拿旧版文档写新版代码；
3. **API 参考 vs 指南**：指南（Guide）学思路，
   参考（Reference）查细节，都读；
4. **英文原文优先**：翻译滞后半年起，
   且术语「查原文」建立英语思维（[程序员英语](../../articles/english-for-devs.md)）；
5. **结合本站文章**：每个领域本站都有对应笔记，
   文末都链了官方文档 —— 两边对照，最快。

## 八、文档打不开/太慢

国内访问部分文档慢：

- **GitHub Docs**：间歇慢，多刷新或找镜像；
- **typescriptlang.org**：用中文镜像；
- **kubernetes.io**：有中文版（kubernetes.io/zh-cn）；
- **通用方案**：DevTools 装「GitHub 加速」类扩展
  （谨慎选择），或本地起代理。

## 小结

文档门户一页收：**MDN（前端圣经）、各框架官方中文站
（Vue/React/TS）、dev.mysql.com + redis.io（数据）、
docs.docker.com + kubernetes.io（运维）**。
遇到问题第一反应查官方文档 —— 这个习惯，
比收藏一百个教程博文值钱。
