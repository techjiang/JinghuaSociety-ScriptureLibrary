笔记软件是「第二大床」（仅次于编辑器）。选错了，
知识管理变成「软件评测」。这篇按**数据哲学**分四类，
帮你按需求选，而不是按热度。

## 一、先想清楚：你的笔记是干嘛的

```text
个人知识库（长期、私密、关联） → Obsidian
团队协作（共享、结构化、流程）  → Notion/飞书/语雀
快速收集（剪藏、稍后处理）      → 各家的 web clipper
公开输出（博客替代）            → 静态站点（本站这种）
```

**大多数人要两种：个人库 + 团队工具。** 别指望一个软件
通吃。

## 二、Obsidian：本地优先的个人库

**哲学**：Markdown 文件在你硬盘上，软件只是编辑器。

**优点**：

- **数据是你的**：纯 .md 文件，Git 管理，五十年后还能打开；
- 双链 + 关系图谱：知识「长」出来，不是「堆」出来；
- 插件生态几千个（Dataview、Templater、Excalidraw…）；
- 免费（个人用，同步收费）。

**缺点**：

- 协作弱（多人同库会冲突）；
- 移动端体验一般；
- 插件装多了会乱（克制！）；
- 上手门槛：不是「打开就写」，要建点结构。

**适合**：程序员、研究者、长期知识管理者。
**本站文章的所有草稿就在 Obsidian 里。**

## 三、Notion：块级一切的协作怪兽

**哲学**：Everything is a block —— 页面、表格、看板全是
「块」的组合，数据库视图无敌。

**优点**：

- 团队协作顶级（评论、权限、模板）；
- Database 视图（表格/看板/日历/画廊）一套数据多种看；
- 模板生态丰富；
- API 开放（能玩出花）。

**缺点**：

- **国内访问慢**（没服务器，硬伤）；
- 离线弱（本质是网页）；
- 数据在它手里（导出格式坑过用户）；
- 高级功能收费（个人免费档够用，团队贵）。

**适合**：团队 wiki、项目管理、内容日历。
**个人重度笔记慎选**（慢 + 数据不在本地）。

## 四、语雀：阿里出品的中产答案

**哲学**：结构化知识库，像「写书」一样组织。

**优点**：

- 国内访问快，稳定；
- 编辑器体验好（表格、画板、代码块）；
- 适合团队文档、产品文档；
- 和阿里生态（钉钉）打通。

**缺点**：

- 个人免费档有限制（公开文档数量等）；
- 数据导出格式自有（锁定期风险）；
- 社区/模板不如 Notion 活跃。

**适合**：国内团队文档库、技术文档中心。
**注意版权和导出条款**（改过几轮，用前看最新的）。

## 五、飞书文档：协作流程向

**哲学**：文档即协作 —— 和 IM、日历、审批深度绑定。

**优点**：

- 国内访问最快最稳；
- 多人实时编辑体验好；
- 和飞书套件一体（会议、任务、OKR）；
- 免费档大方。

**缺点**：

- 个人知识管理弱（强协作弱组织）；
- 数据迁移难（格式自有）；
- 「文档追着流程跑」，不适合沉淀型知识。

**适合**：已在飞书生态的团队。
**不适合**：个人长期库。

## 六、其他值得知道

- **Logseq**：Obsidian 的大纲流对手（每天一页的日志式）；
- **思源笔记**：国产，本地优先 + 双链，数据自主；
- **Joplin**：开源、E2EE 同步，隐私党；
- **Typora**：纯粹的「所见即所得 Markdown 编辑器」——
  写比管强，适合「写多于理」的人；
- **VS Code + Markdown**：极客方案，本站文章就这么写的
  （配合 git 和搜索，管理成本几乎为零）。

## 七、选型决策表

```text
你最在意的是？
├─ 数据永远属于我、离线可用 → Obsidian
├─ 团队协作、项目管理 → Notion（能接受慢）/ 飞书（国内）
├─ 国内快 + 团队文档 → 语雀
├─ 隐私至上、开源 → Joplin / 思源
├─ 就是爱写、不爱整理 → Typora / VS Code
└─ 公开输出 → 直接建站（VuePress，本站教程有）
```

**我的组合**：Obsidian（个人库，git 备份）+ VS Code
（本站文章）+ 飞书（团队协作）。三个各司其职，
不追求「一个软件装下所有」。

## 八、迁移忠告

1. **先确定「数据的家」**：纯 Markdown 文件 + git，
   在任何软件里都是可携带的。被某个软件的格式锁死，
   迁移时哭；
2. **别反复搬家**：Obsidian → Notion → 语雀 → 回来……
   每次迁移一周，知识没涨；
3. **结构极简**：文件夹三层以内。分类越细，越不会去整理 ——
  「懒得分类」是知识管理的头号死因；
4. **搜索 > 分类**：现代笔记软件的搜索够强，
  「全扔进收件箱 + 搜」比「精心归档」更可持续。

## 小结

笔记软件四类哲学：**Obsidian 本地优先、Notion 块级协作、
语雀结构化、飞书流程绑定**。选型先问「数据归谁、
协作与否、国内访问」，再按表选。最重要的认知：
**工具服务思考，别让整理变成表演** —— 
「写了什么」比「用什么写」重要一万倍。
