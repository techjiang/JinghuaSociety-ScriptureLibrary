想写博客，第一条岔路：**自己搭（静态生成器）** 还是
**住平台（公众号/知乎/掘金）**？这不是技术题，
是「成本和自由」的账。这篇算三本账。

## 一、三条路线

```text
A. 自建静态站（VuePress/Hexo/Astro + Pages/Netlify）
B. SaaS 平台（公众号、知乎、掘金、语雀、Notion）
C. 社区专栏（Dev.to、Hashnode、Medium）
```

## 二、账本一：钱

| | 自建 | SaaS |
| --- | --- | --- |
| 服务器 | 0-60 元/年（Pages/Netlify 免费；国内云要备案+钱） | 0 |
| 域名 | 60 元/年（可选） | 0（平台二级域名） |
| 时间成本 | 搭站半天到几天，维护偶尔 | 0（注册即写） |
| 数据导出 | 随时（Markdown + git） | 看平台脸色 |

**自建的真实成本不是钱，是「折腾时间」** ——
搭站两小时很爽，配 HTTPS、搞评论、改样式会持续消耗热情。
（[本站教程](../build-blog-with-plume.md)把这条路铺平了。）

## 三、账本二：自由与控制

| | 自建 | SaaS |
| --- | --- | --- |
| 内容审查 | 无（你的服务器） | 有（平台规则，说夹就夹） |
| 样式定制 | 完全自由 | 套模板 |
| 功能扩展 | 无限（评论/搜索/RSS/PWA） | 平台给什么用什么 |
| 域名 | 自己的（品牌资产） | 平台子域（帮平台引流） |
| 广告/变现 | 自己说了算 | 平台分成/限制 |

**自建的终极价值：所有权**。平台账号是「租的」，
说封就封、说没就没（见过运营五年公众号被误封的）。
自己的站是「买的」，只要域名续费、仓库还在，内容就在。

**平台的终极价值：流量**。写了发在掘金/公众号，
有推荐位、有读者；自己的站，**前半年没人看是常态**。

## 四、账本三：读者从哪来

```text
平台：算法推荐 + 社区关注    → 起步有读者
自建：搜索引擎 + 外链订阅    → 起步零读者
```

**现实策略：平台引流 + 自建沉淀。**

```text
文章写在自建站（源）
  → 同步/转载到平台（引流：掘金/知乎/公众号）
  → 平台文末放「原文链接」（导回自建站）
```

主阵地是自建站（内容资产），平台是「广告牌」。
别反过来（只在平台发，那是给平台打工）。

## 五、SaaS 平台简评

| 平台 | 适合 | 注意 |
| --- | --- | --- |
| 微信公众号 | 大众读者、私域 | 打开率下滑、审核、导出难 |
| 知乎 | 技术问答沉淀 | 长文流量一般 |
| 掘金 | 前端技术圈 | 技术向纯，其他领域弱 |
| 语雀 | 知识库、文档 | 个人站感弱 |
| Notion + Super 等 | 快速搭站 | 国内访问 |
| Dev.to / Hashnode | 英文技术圈 | 需英文 |

## 六、静态生成器选型（自建路线）

| 生成器 | 特点 |
| --- | --- |
| **VuePress + Plume** | 本站同款，文档+博客一体，中文友好 |
| Hexo | 老牌，主题最多，Node 生态 |
| Astro | 现代，多框架，性能狂魔 |
| VitePress | Vue 官方，轻快，文档向 |
| Hugo | Go 写的，构建极快，主题多但配置略老派 |
| Jekyll | GitHub Pages 原生支持，Ruby |

**新手推荐**：VitePress（简单）或 VuePress+Plume
（本站这套，功能全）。**别纠结，写完第一篇再换都来得及。**

## 七、我的建议

按「你是谁」对号入座：

```text
就想写、不想折腾          → 掘金/语雀（先写起来）
要品牌、要长期、不怕折腾   → 自建（本站路线，教程现成）
主要给大众看、要变现       → 公众号 + 自建同步
英文世界发展              → Hashnode/Dev.to + 自建
```

**最重要的认知**：**平台是流量，自建是资产，
内容是根基。** 三个都有最好，只有一个的话 —— 
先有「内容」（在哪写都行），再谈其他。
见过太多人花两周选平台，一篇没写的。

## 小结

三本账算完：**自建赢在所有权和自由，平台赢在流量和零成本，
社区专栏赢在国际曝光**。务实路线：自建为主阵地 +
平台做引流 + 内容持续产出。工具选型别纠结 ——
[VuePress 教程](../build-blog-with-plume.md)现成，
今天的任务是想清楚「写什么」，不是「用什么写」。
