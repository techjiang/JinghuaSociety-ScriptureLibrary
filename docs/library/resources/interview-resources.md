# 面试准备资源与策略

面试是门独立「技术」：有人天天刷题挂在项目深挖，
有人裸拿大厂 offer。差别在准备策略。这份讲资源，
也讲「怎么准备」这个元问题。

> 立场：本人面过也被面过。策略个人向，供参考。

## 一、八股文：绕不开的基本盘

国内面试，「八股」（概念问答）占比高，躲不掉。

**本站就是复习资料**：教程区的 20 篇 + 技术区的 20 篇，
覆盖 HTTP、缓存、事件循环、TCP、CORS、安全、Redis、
MySQL 索引 —— 恰好是八股高频区。**复习时用「讲给别人听」
检验**：能合着文章讲明白，才算懂。

**其他来源**：

- [JavaGuide](https://javaguide.cn)：Java 向最全八股；
- [前端面试题合集](https://github.com/wanglin2/interview)：
  前端高频题整理；
- 《剑指 Offer》：算法 + 思路，经典。

**正确姿势**：八股是「体检表」不是「圣旨」。
问 `==` 和 `===` 的区别只是开场，
后面一定跟「那什么时候会用到隐式转换」——
**理解比背诵抗追问**。

## 二、算法：刷多少才够

| 目标 | 建议量 |
| --- | --- |
| 中小厂/实习 | HOT 100 + 常见简单题，150 题 |
| 大厂（非算法岗） | HOT 100 + 中等 100，250 题 |
| 算法岗 | 竞赛奖牌或专项训练，另开一篇 |

**平台**：

- [LeetCode 力扣](https://leetcode.cn)：国内主流；
- [CodeTop](https://codetop.cc)：按「公司+频率」筛题，
  面哪家刷哪家，精准打击。

**方法**：

1. **按标签刷**：数组 → 链表 → 二叉树 → 动态规划，
  一类一类打通，比随机刷效率高；
2. **二刷错题**：错题是金矿，考前只看错题本；
3. **限时模拟**：学会「15 分钟没思路就说思路」——
  面试考的是沟通，不是沉默地 AC；
4. **手撕**：白板/共享文档写代码，没自动补全，
  平时就要练「无提示写快排」。

## 三、项目：深挖比堆料重要

面试官深挖项目，三个致命问题：

1. 「这个项目你负责哪部分？」→ **说不清 = 假项目**；
2. 「为什么用 X 不用 Y？」→ **没想过 = 抄的**；
3. 「如果流量涨十倍，哪里先挂？」→ **没意识 = 没思考过**。

**准备方法**：拿 STAR 法则给每个项目写一页纸：

```text
S 背景：解决什么问题，用户是谁，规模多大
T 任务：我负责什么，难点在哪
A 行动：技术选型 + 为什么，遇到什么坑怎么爬的
R 结果：数据提升（QPS/耗时/转化），复盘反思
```

**没有亮眼项目怎么办**：做一个。
本站（静态博客+CI 部署）就是「完整工程」样本：
设计→开发→部署→SEO 全链路。面试讲「我搭了个站，
顺手搞了自动化部署和 RSS」—— 比「商城系统（跟做的）」可信。

## 四、系统设计（中高级）

- **入门**：[System Design Primer](https://github.com/donnemartin/system-design-primer)（有中文版）；
- **套路**：需求澄清 → 容量估算 → 高层设计 → 数据模型 →
  详细设计 → 瓶颈与扩展。**先问清楚再画图**，
  直接画 URL 短链的，大概率挂；
- **练习**：找 mock interview 平台（[ interviewing.io](https://interviewing.io)、
  Pramp）真人对练，自己看书没反馈。

## 五、HR 面与谈薪

**HR 面不是走过场**：「你的缺点是什么」考察自我认知，
「为什么离职」考察稳定性。准备：真诚 + 具体 + 不甩锅。

**谈薪**：

1. **先了解市场价**：[ Levels.fyi](https://www.levels.fyi)（外企）、
   OfferShow（国内 offr 展示）、脉脉职言（水分自己甄别）；
2. **不先报数**：被问期望薪资，回「相信贵司有合理的体系，
   我期望在范围内偏上」—— 除非你手握 competing offer；
3. **用 offer 抬价**：有竞品 offer 就明说，这是议价资本；
4. **看 total package**：月薪 × 16 还是 × 12，公积金比例，
  签字费，股票 —— 别只比月薪。

## 六、时间线建议

```text
T-8 周：定目标公司/岗位，JD 逐条对标，补短板
T-6 周：八股系统过 + 按标签刷算法
T-4 周：项目 STAR 打磨 + 系统设计入门
T-2 周：错题复习 + mock interview + HR 面准备
T-1 周：调整状态，不熬夜，只复习不学新
```

**别裸辞备考**（除非存款厚）。在职面试，心理优势大得多 ——
「不行拉倒」和「下个月房租」是两种心态。

## 七、心态

面试是双向选择。挂一场不代表你菜，
可能是匹配度、可能是面试官心情、可能是 HC 冻结。
**把每次面试当「免费的技术交流」** ——
问倒你的问题，就是你的下一个学习清单。
挂了，记下问题，补上，下一场更硬。

## 小结

面试三板斧：**八股理解着背（本站技术区复习）、
算法按标签刷 250 题、项目用 STAR 讲透**。
中高级补系统设计，最后 HR 面真诚应对。
最重要一条：面试是检验不是审判 —— 
被问住的地方，就是你该长进的坐标。
