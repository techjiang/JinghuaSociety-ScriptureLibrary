AI 编程工具已经从「尝鲜」变成「日常」。工具一多，选择困难症也来了：
补全用哪个？对话用哪个？国产的行不行？这篇按**使用场景**分类对比，
附我自己的组合和「防依赖」纪律。

> 立场声明：以下全是自费或试用过的主观体验，不是广告。
> 价格和政策变动快，下单前以官网为准。

## 一、按场景选，别按热度选

AI 编程工具其实分四类，干的活不一样：

| 类型 | 代表 | 强项 |
| --- | --- | --- |
| 行内补全 | Copilot、Codeium、通义灵码 | 写「你意图明确」的代码 |
| 对话助手 | ChatGPT、Claude、Gemini、文心一言 | 读代码、排错、写方案 |
| AI 编辑器 | Cursor、Windsurf、通义灵码 IDE | 全项目上下文 + Agent 改代码 |
| CLI/Agent 工具 | Claude Code、Aider、Copilot CLI | 终端里跑多文件任务 |

大部分人的组合是：**一个补全 + 一个对话**，编辑器用不用 AI 看习惯。

## 二、行内补全三强

**GitHub Copilot**（$10/月，学生免费）

老牌，tab Accept 的鼻祖。补全稳定，VS Code/JetBrains/Neovim 全支持。
2025 年后加了对话和 Agent 模式，但**核心价值还是行内补全**。
适合：所有人，无脑首选。

**Codeium**（个人免费）

免费档慷慨（不限量补全），速度不差。付费版才有更强的对话/Agent。
适合：预算零的个人开发者、学生。

**通义灵码**（国内免费）

阿里出品，中文注释理解好，国内网络稳定。补全质量在第一梯队边缘，
但**免费 + 中文场景**是杀手锏。适合：国内个人开发者平替。

## 三、对话助手：按任务选

**Claude**（Anthropic）

长上下文（一次能喂整个中型项目）、代码质量口碑好、
写文档和重构建议尤其细。适合：读大段代码、架构讨论、写技术文档。

**ChatGPT**（OpenAI）

全能选手，插件生态大，GPT-4o/5 响应快。适合：日常问答、
快速原型、多模态（贴图问问题）。

**Gemini**（Google）

和 Google 生态（Gmail、Docs、搜索）打通，长上下文同样强。
适合：已经在 Google 工作流里的人。

**国产**（DeepSeek、Kimi、豆包、文心一言）

DeepSeek 代码能力意外能打且便宜；Kimi 长文本读论文/文档强；
共同优势：**国内直连、中文好、便宜**。劣势：英文资料覆盖和
前沿模型仍有差距。

**我的用法**：排错和读代码用 Claude，快速问答用 ChatGPT，
写中文文档用国产（网络稳、不要魔法）。

## 四、AI 编辑器：换还是不换

**Cursor**（$20/月）

VS Code 分支，AI 深度融合：`Cmd+K` 行内改代码、`Cmd+L` 对话带
全项目上下文、Agent 模式多文件自动改。迁移成本低（VS Code 配置能导入）。

**Windsurf**（Cognition 出品）

Cascade 模式是亮点：AI 持续跟踪你的操作，主动建议下一步。
体验流畅，生态新。

**换编辑器的理由**：全项目上下文确实是降维打击 ——
普通对话要手动贴文件，Cursor 直接懂你的项目。
**不换的理由**：订阅费、隐私（代码过第三方服务器）、
VS Code + Copilot 已经够用。

**结论**：重度写代码的人值得订阅一个月试试；浅用的话
VS Code + 插件组合性价比更高。

## 五、终端 Agent：新战场

**Claude Code** / **Aider** / **Copilot CLI**

在终端里描述需求，AI 自己读代码、改多个文件、跑测试、提交。
适合「大活」：批量重构、加功能、跑迁移脚本。

注意：**能力越强越要看着**。Agent 改十个文件，你得逐个 review ——
它自信满满删掉你认为关键的代码时，可不会犹豫。

## 六、使用纪律（防依赖）

工具越强，人越容易退化。我的五条纪律：

1. **生成的代码全读一遍再提交**。看着对和真对是两回事，
   边界条件它经常想当然；
2. **不让 AI 决定架构**。方案自己拿，AI 补充细节 ——
   反过来做，代码会变成四不像；
3. **保留「无 AI」能力**。每周找点时间纯手写，保持手感 ——
   哪天工具挂了/限流了，你不抓瞎；
4. **敏感代码不走第三方**。公司核心代码注意合规，
   能用本地部署（如某些企业版）就别过公网；
5. **提示词当代码管理**。好用的 prompt 存起来，是资产。

## 七、组合推荐（按预算）

| 预算 | 组合 |
| --- | --- |
| 0 元 | 通义灵码/Codeium（补全）+ DeepSeek/Kimi（对话） |
| $10/月 | Copilot + 免费对话工具 |
| $20-30/月 | Cursor（含补全对话）或 Copilot + Claude Pro |
| 不差钱 | Cursor + Claude Max，全都要 |

## 小结

AI 编程工具 2026 年的格局：**补全免费化（国产/Codeium）、
对话按特长分工、编辑器 Agent 化**。选型看场景不看热度，
核心纪律只有一条：**方向盘在你手里，它只是副驾驶**。
把它当「速度」，别把它当「脑子」。
