# 速查表合集

有些东西天天用，但记忆总有死角。速查表就是给这些死角准备的 ——
收藏几个靠谱的，比在脑子里存一百个模糊印象强。
这份收「真的会反复打开」的速查资源。

## 二、Git

- **[Git Cheat Sheet（官方）](https://training.github.com/downloads/zh_CN/github-git-cheat-sheet/)**：
  GitHub 官方中文版，一页纸，打印友好；
- **[Git 飞行规则](https://github.com/k88hudson/git-flight-rules)**（有中文）：
  按「出事场景」组织的速查 —— 「我 commit 错了怎么办」
  「我 push 了不该 push 的」—— 比按命令分类实用；
- **[Learn Git Branching](https://learngitbranching.js.org)**：
  可视化学分支/合并/rebase，交互式关卡。
  **理解 rebase 和 merge 的区别，玩这个游戏半小时顶看书三天**。

## 三、Linux / 命令行

- **[Linux 命令大全](https://www.linuxcool.com)** / **[Linux 命令速查](https://cheat.sh)**：
  中文全，按功能分类；
- **[explainshell](https://explainshell.com)**：贴一条命令进去，
  逐参数解释。读别人写的复杂命令神器；
- **[commandlinefu](https://www.commandlinefu.com)**：命令行技巧投票榜，
  淘金处。

## 四、正则

- **[regex101](https://regex101.com)**：在线测试 + 逐字符解释
  （本站正则文首推）；
- **[RegexLearn](https://regexlearn.com)**：游戏化学正则，
  零基础友好；
- **[iHateRegex](https://ihateregex.io)**：按「我要匹配什么」
  组织的模式库（邮箱、URL、IP…复制即用）。

## 五、HTTP / 网络

- **[HTTP Status Dogs](https://httpstatusdogs.com)** /
  **[HTTP Cats](https://http.cat)**：用猫猫狗狗图记状态码，
  过目不忘（严肃场合请用 [MDN](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Status)）；
- **[Mozilla HTTP 文档](https://developer.mozilla.org/zh-CN/docs/Web/HTTP)**：
  权威参考，收藏当字典。

## 六、CSS

- **[CSS Reference（codrops）](https://tympanus.net/codrops/css_reference/)**：
  每个属性的可视化演示，比文档直观；
- **[Can I use](https://caniuse.com)**：兼容性查询标准答案；
- **[Flexbox Froggy](https://flexboxfroggy.com)** + **[Grid Garden](https://cssgridgarden.com)**：
  游戏化学布局，本站 CSS 文推过。

## 七、JavaScript / 前端

- **[JavaScript 秘密花园](https://bonsaiden.github.io/JavaScript-Garden/zh-Cn/)**：
  老但经典，讲 JS 的坑；
- **[现代 JavaScript 教程](https://zh.javascript.info)**：
  系统教程兼速查；
- **[You Don't Know JS 中文](https://github.com/getify/You-Dont-Know-JS)**：
  免费在线读。

## 八、数据库 / SQL

- **[SQLBolt](https://sqlbolt.com)**：交互式 SQL 练习
  （本站 SQL 文首推）；
- **[SQL 速查表](https://www.w3schools.com/sql)**（W3C 风格）：
  语法大全；
- **[MongoDB 官方速查](https://www.mongodb.com/developer/products/mongodb/cheat-sheet/)**：
  用 Mongo 的备着。

## 九、DevOps / Docker

- **[Docker Cheat Sheet](https://docs.docker.com/get-started/docker_cheatsheet.pdf)**：
  官方一页纸；
- **[Nginx 配置速查](https://nginxconfig.io)**：在线生成 Nginx 配置
  （静态站、反向代理、WordPress 模板都有）——
  比手写快，比抄的懂。

## 十、使用建议

速查表的正确用法：

1. **少而精**：每个领域留一两个，别收藏十个用零个；
2. **用完就搜**：记不住没关系，知道「去哪查」就是高手；
3. **打印/置顶**：真正高频的（Git 命令、Linux 常用），
   打印贴墙或设浏览器首页 —— 看得见的才用得上；
4. **定期淘汰**：半年没打开的收藏，删。

## 小结

速查表核心就五个站：**regex101（正则）、caniuse（兼容）、
explainshell（命令）、http.cat（状态码）、
learngitbranching（Git 分支）**。其他按领域补充。
终极心法：**善用搜索，别处记忆** —— 
大脑该用来理解，不是当字典。
