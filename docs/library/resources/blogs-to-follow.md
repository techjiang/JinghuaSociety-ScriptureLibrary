公众号追热点、知乎看争论，但**深度技术内容还是在个人博客**。
一个人几年如一日地写，本身就是质量筛选。这份收我订阅列表里的，
中外混排。

## 一、国内博客

### 阮一峰的网络日志

十六年没断更。内容广：技术、工具、随笔、周刊。
「科技爱好者周刊」是每周必读。**中文技术写作者的天花板**。

### 张鑫旭 - 鑫空间

CSS 领域国内最深的博主，十年只写 CSS。
「CSS 选择器世界」「CSS 新世界」作者。搞前端的，
他的 CSS 系列文章值得全翻一遍。

### 淘宝前端团队（FED）博客 / 政采云 / 字节前端

团队博客，质量高于平均水平（有 review 机制）。
工程实践、性能优化、Node 全栈都有。

### 李辉 - GreyLulu

Nginx/OpenResty 向，运维开发干货。

### 小涂 - 半个前端

折腾向：自建服务、家庭实验室、全栈实践。
「独立开发者」生活方式样本。

### 卡尔的 AI 工具箱

AI 工具测评，更新快，适合跟 AI 动态。

## 二、海外博客（英文）

### [Julia Evans](https://jvns.ca)

「是什么 + 为什么」的典范。Linux、网络、数据库都用
漫画式图解讲。**技术写作的教科书**。

### [Dan Abramov](https://overreacted.io)

React 核心团队成员。文章少而精，讲 React 心智模型。
「Before you memo」这类，读一遍顶十篇优化文。

### [Martin Fowler](https://martinfowler.com)

软件架构的「史记」。微服务、重构、持续交付的
概念都从他这出来。长文多，值得慢读。

### [2ality（Dr. Axel Rauschmayer）](https://2ality.com)

JavaScript 权威解读，ES 新特性第一时间深度文。
ES6/ES7 系列是经典。

### [Faster than Seven](https://fasterthanseven.net)

全栈/工程文化，观点犀利。

### [Simon Willison](https://simonwillison.net)

Django 联合作者、AI 工具圈最活跃的写作者之一。
LLM 应用实践第一手记录。

## 四、怎么订阅

**RSS 阅读器 + OPML** 是标准姿势：

1. 选阅读器：**Inoreader**（网页端强）、**Reeder**（苹果生态）、
   **Folo**（开源新秀，推荐源分享方便）；
2. 订阅源：上面每个博客都有 RSS/Atom（找页面里的橙色图标
   或 `/feed.xml`）；
3. 配好「稍后读」：Pocket/Instapaper 收长文，通勤读。

**本站也提供 RSS**：[feed.xml](../feed.xml) —— 
地址栏图标一键订阅，和上面这些博客放同一个阅读器里。

**订阅原则**（老生常谈但重要）：二十个源封顶，
每周清一次未读。博客是慢节奏的，追更心态要不得。

## 五、发现新博客的渠道

- **RSS 源推荐**：[中文博客列表](https://github.com/timqian/chinese-independent-blogs)、
  [BlogHub](https://bloghub.fun)（中文博客聚合）；
- **链式发现**：好博客的友链页和「推荐阅读」里，
  常有同好 —— 本站[友链页](../links/)就是干这个的；
- **Newsletter 里的链接**：阮一峰周刊里的文章链接，
  一半来自个人博客。

## 小结

博客订阅核心名单：**阮一峰（中文综合）、张鑫旭（CSS）、
Julia Evans（图解）、Dan Abramov（React）、
Martin Fowler（架构）**。五个覆盖八成营养。
用 RSS 订阅，别看在收藏夹里吃灰 —— 
信息管理的终点是「主动获取」，不是「被动投喂」。
