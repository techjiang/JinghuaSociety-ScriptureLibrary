# 前端书单：读过才敢推荐

书单这东西，收藏一百本不如读透三本。这份是我真读完（或真啃过）
的，按学习阶段排，每本配一句大实话。没读过的不放。

## 一、入门：能跑起来再说

### 《Head First HTML 与 CSS》

入门圣经，图多字少，看得进去。缺点：例子有点老旧，
HTML5 之后的内容自己补。

### 《JavaScript 高级程序设计（第 4 版）》（红宝书）

前端人的「字典」。不用通读，当工具书翻 —— 
DOM、事件、Ajax 查它。第 5 版改版后评价两极，
第 4 版依然是经典。

### 《CSS 揭秘》

47 个 CSS 技巧，每篇短小精悍。看完的收获不是技巧本身，
是「CSS 还能这么想」的思维方式。

## 二、进阶：知其所以然

### 《你不知道的 JavaScript（上中下）》

上卷讲作用域闭章、this，中卷讲类型异步，下卷讲 ES6。
**上卷必读**，中卷选读，下卷当参考。
作者 Kyle Simpson 有点啰嗦，但确实讲透了。
本站有[读书笔记](../articles/reading-js-book.md)。

### 《JavaScript 语言精粹》（蝴蝶书）

老书（ES5 时代），薄。精华是「语法好的部分」这个视角 ——
理解 JS 的设计取舍，半天读完，回味很久。

### 《深入理解 ES6》/《深入理解 ES6+》

ES6 特性逐项讲透。适合「用了两年 ES6 但说不清 Proxy 和
Reflect 区别」的人。

## 三、框架：跟着官方文档走

说句实话：**Vue/React 的官方文档比大多数书好**。
要买书的话：

### 《Vue.js 设计与实现》

霍春阳（Vue 核心团队成员）写的 Vue 3 响应式原理剖析。
想理解 Vue 内部，这是唯一选择 —— 其他 Vue 书都是 API 介绍，
不如看文档。

### 《React 设计原理》

Dan 团队出品，讲 React 的心智模型（JSX、fiber、hooks 为什么
这么设计）。比任何「21 天精通 React」值得读。

## 四、工程化：从写到能上线

### 《深入浅出 Webpack》

Webpack 的原理 + 实战。现在 Vite 当道，但 Webpack 的
打包思想（loader/plugin/依赖图）依然值得懂 ——
Vite 的文档假设你懂这些。

### 《前端架构：从入门到微前端》

偏架构视角：模块化、组件化、性能、部署。
工作三五年后会「原来如此」的一本。

## 五、性能与体验

### 《Web 性能权威指南》

Google 性能团队出品，网络层到渲染层全覆盖。厚，但当手册。
配合本站的[性能优化清单](../web-performance.md) 看。

### 《高性能网站建设指南》+《高性能网站建设进阶指南》

老但经典，14 条性能规则至今有效。薄，一个周末读完。

## 六、软技能：程序员的另一半

### 《代码整洁之道》

Clean Code。观点有争议（「函数小于 20 行」被吐槽教条），
但命名、注释、错误处理的讨论依然值。**批判着读**，
别当圣经。本站有[读书笔记](../articles/reading-clean-code.md)。

### 《重构：改善既有代码的设计》

Martin Fowler。不是通读书，是「手法 catalogue」——
闻坏味道 → 查手法 → 照着重构。配合重构工具用。

### 《程序员修炼之道》

务实的哲学：DRY、正交性、曳引……每条都是经验结晶。
每年重读一遍，感受不同。

## 七、阅读建议

1. **入门别囤书**：一本红宝书 + 官方文档够起步；
2. **进阶读原理**：《你不知道的 JS》+《Vue 设计与实现》打通任督二脉；
3. **书配实践**：每本书的示例都动手敲，只看不写等于没看；
4. **英文原版优先**：技术书翻译质量参差，有能力的看原版
   （`it-ebooks` 这类站的道德问题自己权衡，正版渠道推荐
   O'Reilly 在线阅读）。

## 小结

如果只读五本：**红宝书（查）、《你不知道的 JS》上卷（懂）、
《Vue.js 设计与实现》或 React 设计原理（框架）、
《重构》（手法）、《程序员修炼之道》（道）**。
其他按需。书是便宜的，时间是贵的 —— 读透比读多重要。
