技术书不便宜，一本五六十。这篇收**合法免费或低价**的
电子书渠道，以及找书的方法。原则：**支持正版，
但别当冤大头**（有些书真的可以在官方渠道免费读）。

## 一、出版社官方免费/试读

很多技术书**官方就提供免费电子版**（作者或出版社主动放出的）：

| 系列/书 | 渠道 |
| --- | --- |
| O'Reilly 旗下大部分书 | [oreilly.com](https://www.oreilly.com)  trial + [oreilly.org](https://www.oreilly.org) 部分免费 |
| 《You Don't Know JS》 | [GitHub 免费读](https://github.com/getify/You-Dont-Know-JS)（作者公开） |
| 《Eloquent JavaScript》 | [eloquentjavascript.net](https://eloquentjavascript.net) 官网免费全文 |

| 《The Book of Secret Knowledge》 | [GitHub](https://github.com/trimstray/the-book-of-secret-knowledge) |
| 《OSTEP 操作系统导论》 | [pages.cs.wisc.edu](https://pages.cs.wisc.edu/~remzi/OSTEP/) 作者官网免费 |
| 《DDIA》 | 有民间在线翻译版，英文官网有免费读政策 |
| 图灵/人邮/机工 | 官网/公众号常放试读章节 + 样章 PDF |

**先查「官网有没有免费版」** —— 很多经典书作者
故意开放网络版（为了影响力）。

## 二、开源电子书合集（GitHub）

搜 `free-programming-books`：

- [free-programming-books](https://github.com/EbookFoundation/free-programming-books) ——
  **史上最全**，多语言分语种，中文区资源丰富；
- [awesome-programming-books](https://github.com/royeo/awesome-programming-books) ——
  中文向整理；
- [深入理解计算机系统等](https://github.com/duguosheng/...) 各类主题清单。

**用法**：当「索引」用 —— 它告诉你「哪本书有免费版」，
然后去官方渠道读。**别用来找盗版**（下面说）。

## 四、在线阅读环境

- **Koodo Reader**：开源本地电子书管理器
  （EPUB/PDF/Mobi），笔记高亮同步；
- **微信读书**：技术书越来越多（部分要会员），
  手机通勤读方便；
- **Z-Library**：知道的人都知道 ——
  **法律灰色，不推荐、不展开**，出了事别找我；
- ** Anna's Archive**：同上。

**正版觉悟**：技术书作者版税不高（技术书市场小），
能支持就支持（纸电同买、打折入）。真没预算：
图书馆、公司报销、开源版，路子多的是。

## 五、找书的方法

**技术书单**：本站的[前端书单](../books-frontend.md)和
[后端书单](../books-backend.md) 都带点评 ——
先看「值不值得读」再买，别冲动。

**判断一本书的好坏**（下单前）：

1. 看**出版年份**：技术书过时快，五年外的慎买
  （经典除外：重构、代码整洁之道这类讲思想）；
2. 看**豆瓣/Goodreads 评分 + 最新书评**：
  中差评说什么（翻译烂？例子旧？）；
3. **看目录**：是不是覆盖你真想学的问题；
4. **试读**：几乎所有平台都有样章，读两章
  文风不对胃口就换；
5. **避雷信号**：书名带「21 天精通」「从入门到精通」
  且出版社不明的；目录全是 API 罗列的（那是手册不是书）。

**一句话**：**书评区的中差评比好评更有信息量。**

## 六、读书的方法论

买了不等于读了。几个亲测有效的：

1. **功利阅读**：带着问题读（「我要搞懂缓存」→
   翻书对应章节），不用从头读到尾；
2. **速读筛书**：第一遍一小时翻完，值得细读再细读；
3. **代码跟着敲**：技术书的例子，手敲一遍
   （别复制），敲完才是你的；
4. **输出倒逼**：读完写篇笔记
   （[本站文章区](../../articles/) 都是这么来的）；
5. **别囤**：书架上十本未读 = 焦虑发生器。
   「读完再买」虽然理想，「买一本读一本」更现实。

## 小结

电子书资源路线：**官网免费版（Pro Git/YDKJS/OSTEP）→
GitHub 书单索引 → 纸电同买/打折捆包 → 图书馆兜底**。
找书看本站书单 + 中差评，读书带着问题 + 动手敲。
最省钱的不是资源，是**读完** —— 
一本读透，抵过一书架翻过前三页。
