# 技术播客推荐

通勤、做饭、健身的时候，耳朵闲着也是闲着。
技术播客是「被动输入」的好渠道 —— 听到感兴趣的话题，
再回头深挖。这份收我常听的，中文为主。

## 一、中文技术播客

### 代码之外（Beyond Code）

从业者访谈，聊职业发展、技术选择、人生选择。
不聊具体语法，聊「程序员这个活怎么干」。
适合：对职业路径迷茫的人。

### 内核恐慌

两位主播聊系统底层、开源文化、极客话题。硬核但有趣，
Linus 式的暴论时有。适合：喜欢听观点碰撞的人。

### 津津乐道

综合性科技播客，覆盖 AI、硬件、互联网动态。更新勤，
时效性强。适合：保持行业敏感度。

### 捕蛇者说

Python 向，聊 Python 生态、开源项目、开发者故事。
Python 程序员的最佳陪伴。

### 疯投圈 / 半拿铁

偏商业科技，聊聊公司、产品、商业模式。技术人懂点商业，
不是坏事。

## 二、英文技术播客（练耳朵）

### Syntax

前端向，Scott 和 Wes 主持。新框架、工具、实战技巧，
语速正常、内容丰富。**前端人的英语听力第一台**。

### The Changelog

开源社区动态、项目作者访谈。Nadia 主持，
每期一个开源故事。适合：想了解开源文化的人。

### Software Engineering Daily

偏工程架构，话题深（数据库、分布式、AI 基础设施）。
适合：有一定基础想拓广度的。

### Lex Fridman Podcast

不纯技术，但 AI/科技大佬访谈（Sam Altman、Zuckerberg…
都上过）。长（两小时+），挑感兴趣的听。

## 三、收听建议

**倍速是效率神器**：1.5x 起步，适应后 2x。
同样的时间听双倍内容 —— 播客的信息密度本来就不高，
倍速不损失理解。

**听完要「落地」**：听到好话题，记下来，
当天找资料深入（本站一半选题就是这么来的）。
纯听不练，等于听个响。

**场景搭配**：

```text
通勤（嘈杂）→ 资讯类、访谈类（不依赖全程专注）
做饭/家务（半专注）→ 教程类、对话类
深夜/专注 → 硬核讲座、圆桌
```

## 四、订阅方式

- **小宇宙**（国内首选，中文播客全，评论氛围好）；
- **Apple Podcasts / Overcast**（英文为主）；
- **Pocket Casts**（全平台，功能全）。

本站没做播客（写文章都写不过来），
但如果你开了技术播客，欢迎来[换友链](../links/)。

## 小结

播客是「饭后甜点」不是「主食」—— 知识点从文章和文档来，
播客负责「让你知道有这个东西」和「路上不无聊」。
推荐组合：**代码之外（职业）+ Syntax（前端）+ 津津乐道（资讯）**，
三个覆盖八成场景。
