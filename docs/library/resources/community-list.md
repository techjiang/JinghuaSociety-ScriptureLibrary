# 技术社区与论坛推荐

技术社区是「信息源 + 人脉 + 镜子」（看别人的问题，
照自己的水平）。这份按「中文/英文/垂直」分，附逛法建议。

## 一、中文主力

### V2EX

[v2ex.com](https://www.v2ex.com) —— 创意工作者社区，
「程序员的朋友圈 + 求助站 + 交易区」。

**看什么**：节点「程序员」「分享发现」「问与答」——
技术选型讨论、工具分享、职场吐槽。氛围相对理性，
老用户多。

### 掘金

[juejin.cn](https://juejin.cn) —— 前端向技术文章社区。

**看什么**：前端/Node 新文章、小册（付费，质量参差）、
沸点（短动态）。**适合前端从业者保持敏感度。**

### 知乎

[zhihu.com](https://www.zhihu.com) —— 问答 + 专栏。

**看什么**：技术话题的深度回答（「如何评价 X」
「X 是什么体验」）。注意：抖机灵多，硬核在专栏和少数答主。

### 博客园 / CSDN

- **博客园**：老派程序员聚集地，技术文章质量稳定
  （近年活跃度降，但历史沉淀厚）；
- **CSDN**：量大，质量参差，**但报错信息搜它常能中** ——
  实用向，别笑。

### 少数派 / 即刻

**少数派**：效率工具、数字生活方式
（工作流、App 推荐）。
**即刻**：圈子文化，「一起搞副业」「互联网从业者」
等圈子信息密度高（ App 内）。

## 二、英文必逛

### Hacker News

[news.ycombinator.com](https://news.ycombinator.com) ——
创业 + 技术圈风向标。**评论区比正文值钱系列。**

**逛法**：每天扫前 20 标题，点感兴趣的评论。
[ Hacker News Digest](https://hndigest.com) 收摘要
（没空天天刷的话）。

### Reddit

[r/programming](https://www.reddit.com/r/programming/) ——
技术综合；
[r/webdev](https://www.reddit.com/r/webdev/) ——
前端；
[r/ExperiencedDevs](https://www.reddit.com/r/ExperiencedDevs/) ——
**老鸟讨论区**（职业发展、架构、带团队，干货密度高）。

### Dev.to

[dev.to](https://dev.to) —— 程序员博客社区，
氛围友好（新手提问不被喷）。写英文的练手地。

### Stack Overflow

[stackoverflow.com](https://stackoverflow.com) ——
问答本身。**报错先搜它**，八成有答案。
（提问门槛高，问前先搜 —— 低质问题会被踩到删。）

### Lobsters

[lobste.rs](https://lobste.rs) —— HN 的「小而美」替代，
技术浓度更高（邀请制氛围），话题偏工程实践。

## 四、社区的「正确打开方式」

### 当信息源用（80% 时间）

- 订阅 RSS/Newsletter（[本站同款姿势](../newsletters.md)），
  别沉迷刷新；
- 固定几个社区，别全逛 —— 信息节食比信息摄取难。

### 当镜子用（15%）

- 看别人的问题：**「这题我会不会」** —— 不会的，
  就是你该补的（免费的查漏补缺）；
- 看大佬的回答：学思路和表达（怎么把复杂问题说简单）。

### 当扩音器用（5%）

- **提问前先搜**（三遍）：站内、Google、官方文档；
- 提问给全「环境+复现+已尝试+预期vs实际」
  （[问问题的艺术](../../articles/ask-good-question.md)）；
- **回答问题**：教别人是最佳学习 ——
  哪怕答基础的，也是在整理自己的知识；
- 分享作品：做完东西发「分享发现」节点，
  反馈是最好的鞭子。

## 五、社区礼仪（简版）

1. 搜索后再问；
2. 报错贴全文，别截图一小块；
3. 对回答者说谢谢（哪怕没解决）；
4. 有不同观点说理由，别阴阳怪气；
5. **解决了的帖，回来说一声「按 X 方法解决了」** ——
  后来者会谢谢你。

## 小结

社区配置建议：**中文 V2EX + 掘金（按方向选一个），
英文 HN + Reddit 一个垂直版**，加上 Stack Overflow 当字典。
时间分配「信息源 80 / 照镜子 15 / 出声 5」。
社区的终极价值不是「摸鱼」，是**让你知道世界很大、
自己很小、还能长**。
